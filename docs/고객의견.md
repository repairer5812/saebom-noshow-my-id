# 고객 의견 모음(교육용 가상 자료)

시범 6개 지점 이용자 설문의 자유 응답 가운데 일부입니다.

- 예약해 놓고 깜빡했어요. 전날 알림이 오면 좋겠어요.(대학생, 회기점)
- 현장결제라서 부담 없이 잡아 두게 되는 것 같아요.(직장인, 강남역점)
- 일정이 바뀌면 취소하는 메뉴를 찾기 어려워요.(수험생, 신촌점)
- 예약금이 있으면 노쇼가 줄겠지만 학생은 부담돼요.(대학생, 건대입구점)
- 15분이 지나면 자동으로 풀어 주면 기다리는 사람이 쓸 수 있겠어요.(기타, 판교점)
