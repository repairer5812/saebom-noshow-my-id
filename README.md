# 새봄스페이스 노쇼 대시보드

새봄스페이스 스터디룸 예약 기록에서 노쇼 현황을 확인하는 정적 웹 앱입니다.
새봄스페이스와 아래 데이터는 모두 교육용 가상 자료입니다.

## 배포 주소

[새봄스페이스 노쇼 대시보드 열기](https://repairer5812.github.io/saebom-noshow-my-id/)

## 기능

- 전체 또는 지점을 선택해 예약 기록을 필터링합니다.
- 전체 노쇼율을 표시합니다.
- 결제 방식별 노쇼율을 비교합니다.
- 예약 시점별 노쇼율을 비교합니다.
- 하루 전 알림 대상 건수와 문자비를 계산합니다. 알림 대상은 예약 시점이 당일이 아니고 취소되지 않은 예약이며, 문자비는 1건당 20원으로 계산합니다.
- 같은 `예약ID`가 여러 번 있으면 첫 번째 행만 사용합니다.
- 노쇼율은 `노쇼 ÷ (노쇼 + 이용완료)`로 계산하며, 취소는 분모에서 제외합니다.

## 여는 법

별도 설치나 서버 실행 없이 다음 파일을 브라우저로 열면 됩니다.

- 대시보드: `index.html`
- 브라우저 테스트: `tests.html`

## 테스트

Node.js가 설치되어 있다면 저장소의 루트 폴더에서 다음 명령을 실행합니다.

```bash
node tests/run-node.js
```

브라우저에서 `tests.html`을 열어도 같은 테스트를 확인할 수 있습니다.

## 데이터

`data/bookings.js`에는 2026년 8월 24일부터 10월 18일까지 6개 지점의 8주 예약 기록이 들어 있습니다.
원본은 3,418행이며, 중복 `예약ID`를 정리하면 3,412행입니다.

자료의 열 목록과 계산 기준은 [`docs/자료설명.md`](docs/자료설명.md)에서 확인할 수 있습니다.

## 주요 파일

- `index.html`: 대시보드 화면의 HTML
- `style.css`: 화면 스타일
- `app.js`: CSV 해석, 예약 정제, 노쇼율 및 알림 대상 계산 함수
- `dashboard.js`: 계산 결과를 화면에 표시하고 지점 선택을 처리하는 코드
- `data/bookings.js`: 교육용 가상 예약 기록
- `tests.html`: 브라우저용 테스트 화면
- `tests/tests.js`: 테스트 정의
- `tests/run-node.js`: Node.js 테스트 실행 파일
